# LocalDog 🐶

[English](README_EN.md) | [Русский](README_RU.md)

**LocalDog** — это современный, быстрый и конфиденциальный MTProto-прокси для Telegram Desktop. Он работает локально на вашем компьютере, превращая обычный трафик Telegram в WebSocket-соединения, что позволяет обходить сетевые ограничения без использования сторонних серверов.

---

## ✨ Основные возможности

- **Локальный мост**: Работает прямо на вашем ПК. Никаких промежуточных серверов — ваши данные остаются вашими.
- **WebSocket Туннелирование**: Использует официальные WebSocket-узлы Telegram для максимальной стабильности.
- **Современный GUI**: Красивый интерфейс на PySide6 с поддержкой темной и светлой тем.
- **Умная синхронизация**: Настройки применяются мгновенно, ссылка для Telegram обновляется в реальном времени.
- **Индикация статуса**: Анимированные индикаторы работы и подробная статистика трафика.
- **Автоматизация**: Поддержка автозапуска и сворачивания в трей.

## 🚀 Как начать использовать (Windows)

Для большинства пользователей достаточно скачать готовый `.exe` файл:

1. Перейдите в раздел **[Releases](https://github.com/AlexMacregar/LocalDogTelegram/releases)**.
2. Скачайте последнюю версию `LocalDog.exe`.
3. Запустите файл (установка не требуется, Python не нужен).
4. Нажмите большую кнопку питания в центре экрана.
5. Нажмите **"Open in Telegram"** или скопируйте ссылку и добавьте прокси в настройках Telegram.

## 🛠 Настройка

Вкладка **Настройки** (Settings) позволяет:
- Изменить порт и адрес прослушивания (по умолчанию `127.0.0.1:443`).
- Сгенерировать новый секретный ключ.
- Настроить маршрутизацию для конкретных дата-центров (DC) Telegram.
- Включить автозагрузку.

*Подсказка: Наводите на значки **"?"** в настройках для получения подробной информации о каждой опции.*

## 🔒 Безопасность и Конфиденциальность

LocalDog **не расшифровывает** ваши сообщения. MTProto-трафик шифруется сквозным методом (End-to-End) между вашим клиентом Telegram и серверами Telegram. LocalDog лишь меняет "обертку" трафика с TCP на WebSocket.

Ознакомьтесь с [Политикой безопасности](SECURITY_RU.md).
